# E-Commerce Backend


Backend system for E-Commerce application built with Java Spring Boot.


## Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security
- JWT Authentication
- MySQL 8
- Redis
- RabbitMQ
- Docker
- GitHub Actions


## Architecture

Modular Monolith Architecture


## Modules

- auth
- user
- product
- order
- notification
- shipping
- common


## Features

- Product Management API
- Order Management API
- JWT Authentication
- Role Based Authorization
- Redis Cache
- Message Queue
- External Service Integration
- Docker Deployment
- CI/CD Pipeline
